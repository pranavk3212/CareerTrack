# CareerTrack 🚀

A full-stack job application tracking platform built to help job seekers manage applications, interviews, follow-ups, and career progress.

## Features

### Authentication
- User registration
- Secure login
- JWT-based authentication
- Protected user data

### Application Management
- Add job applications
- Edit and delete applications
- Search and filter applications
- Track application status

### Interview Management
- Interview scheduling
- Interviewer details
- Meeting links
- Interview notes

### Follow-up Tracking
- Follow-up dates
- Next actions
- Upcoming reminders

### Dashboard
- Application statistics
- Pipeline overview
- Recent activity
- Interview tracking

### Analytics
- Application status breakdown
- Progress tracking
- Conversion insights

### User Experience
- Responsive design
- Dark mode
- CSV export
- Modern dashboard UI


## Tech Stack

### Frontend
- React
- Vite
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Authentication
- JWT
- bcrypt
